## 5. 可复现性说明

- **能本地完整复现的**：S0、S1、S4、S5、S6、S9（AiCE）、S10、S11、S12
  —— 只要 `results/` 与 AF3 输出目录在位。
- **需要外部工具的**：S2（AF3 服务器）、S3（两个网页服务器）。
- **需要实验室数据的**：S7、S8。
- **环境限制**：`pptx_build.py` 需 Windows + Office；绘图需 Noto Sans CJK SC 字体。

**已知的记录问题**（统合时建议一并修，详见各批分析报告的「记录问题」节）：

1. 补充突变源表里 `列1` 的**文档定义与算式不符**——说明写「C388 − C871」，
   实测算式是 `C871 ÷ C388`。**连续两批出现**，建议在源表层面统一。
2. 源表保留率用**固定参照 0.8**，而同批亲本实测在 0.67–0.79 之间浮动，
   与同批亲本口径不一致。
3. c.295 的 `0` 应读作「**低于检测线**」而非「无数据」，也不等于真实编辑效率为 0。
4. **建库背景未在源表中逐批记录**——这直接影响哪些数值可以跨批比较。
   建议在源表加一列「建库背景批次」，否则后续无法判断。
