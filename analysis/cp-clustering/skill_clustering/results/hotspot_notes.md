# 关键接触和残基：不同聚类流程的一致性

输入为11个构建的等权均值，每个构建内先平均同一seed的5个结构，再平均seed。全部统计均未读取活性标签。

主比较覆盖6种方法，但仅有3种唯一分区；24个“方法×CP子集”组合也只有3种唯一分区。算法重复输出的分组不构成独立证据。

接触重要度为原始CP尺度的簇间平方和 BCSS = Σₖ nₖ(簇均值−总均值)²；残基分数为所有相接CP的BCSS之和。主排名将每个唯一分区等权计入一次。没有计算ANOVA显著性或把这些自同一数据导出的分组视为外部验证。

不同CP子集的分组先在共同的全部原始CP空间计算BCSS，另列仅保留该子集CP的native排名。固定相同分区时，共同空间排名一致；native排名可反映删去接触本身的影响。

N74和L33的结果最一致：分别为唯一分区等权BCSS第5、12名，三种分区均在前20；保留77/154/230个CP时native排名分别为7/7/5与13/13/12。N74连接Q58、L33等识别邻域，单独限制两端均位于70–153时，这些跨边界接触会被剔除；该受限分析的N74排名为46，不能用它支持跨所有表示都稳定的结论。

F129在共同原始CP空间的BCSS排名为56，三种主分区均未进入前20，其保留依据来自先前T31–F129局部对照。局部差异可存在于同一全局簇内部。F129的留一构建方差排名为10–38，去掉T31D时最靠后。

## 边界和解释

LOCO仅衡量当前突变面板对热点排名的影响：每次去掉一个构建，重算剩余10个构建的无监督方差。它没有预测被留出的构建，也没有评价实验泛化能力。

高BCSS说明接触能够描述当前结构分组；方差热点和BCSS热点都受已有突变设计影响。N23–G27受G27组合变化驱动，N57附近的热点受N57W/N57A分组驱动。局部接触依据和直接催化注释应与全局BCSS排名并列解释。

分子来源和催化角色沿用已核对的序列映射表。APOBEC1来源核心区为70–153，直接催化/锌配位残基为H70、E72、C102、C105。APOBEC3A来源部分也参与整个脱氨酶折叠。序列95位动态读取为W。

低置信标记定义为任一构建均值Cα pLDDT <70，属于模型置信度标记，无法直接解释为实验柔性。没有生成具体氨基酸替换建议或编辑效率预测。
