## 数据与呈现说明

- N1：48 条构建体记录中 36 条比值可定义，12 条不作为 0 绘图。批内实际还包含一个单点比较物 `32F`，因此图例保留 1/2/3 个取代三类；不将全部 48 条误称为双点或三点组合。
- N1：省略可选的其他批次单点背景云，保留要求的 1.371 参考线并明确标注为其他批次亲本；本批亲本比值为 1.192。此参考线不证明跨批可比性。
- N2：选择包内建议的批内名次图；补充批不补名次、不生成绝对比值对比柱图。第三批背景不同，批内名次也不是跨批效应量。附 `source-table.md` 保留三批全部原值。
- N3A：37 条原记录中 35 个有效点；失败孔和另一条比值未定义记录列在坐标外。
- N3B：前两根柱的构建体相差 132E、批次也不同，因此不称为相同构建体重复。第 5 根为原包要求的失败孔记录幽灵柱，白底深珊瑚红描边与斜线，明确标为无效，不解释为活性结果。
- N4：25 个突变体用于散点图，4 个参照组另存。27 位 10 个替换中 7 个 `C295_not_detected=TRUE`；尽管源表存为 0，图中只显示 `n.d.`，不画零值柱，绘图数据保留源值与单独的空白显示值。
- 不添加统计显著性、拟合、误差棒或伪造重复。第三批 `n_samples` 是来源记录数量，不擅自定义为独立生物重复。

## 原包内部差异（未修改源值）

1. 组合批三元组保留率在 N1 文件为 **0.773**，N2/N3 历史记录为 **0.772**。各图使用对应文件的原值，不自行选择或合并。

3. 各列是已经汇总或四舍五入的来源数值，不用其他显示列反算替代。
4. 包内对于跨批 ROF 可比性的说法不完全一致。本次采用保守范围：只显示各批内部名次和内部比较，不宣称归一化已消除建库背景差异，也不把第三批较低绝对比值归因为已证明的特定原因。

## 样式与编辑

- 字体：本机 `/System/Library/Fonts/Supplemental/Futura.ttc` 的 Futura（medium）。N4 的菱形文本符号由 Arial Unicode MS 提供；其余图中文字为 Futura。不分发字体文件。
- 继承上一组 APOBEC 图的 `orca-figure-style.json`，保留旧映射，追加本次新类别。
- 靛紫为主；暖橙 `#E89B3C` 聚焦三元组；青绿 `#27877F` 表示指定比较组及保留率参考线；深珊瑚红 `#AD344C` 专用于失败孔提示。
- PNG 宽 3600 px，300 dpi；N1/N2/N3/N4 高分别为 2700/2250/5100/6900 px。
- SVG 字体转路径，适合矢量缩放与路径编辑；不声称字仍是可编辑文本。修改文字、数据、配色可使用 `plot.py`。
- 无 PowerPoint 文件：本次为纯数据绘图，编辑源为 Python、CSV 与 JSON。

## 复现

需要 Python 3、Matplotlib、NumPy、pandas 和 Pillow；使用本机已有 Futura，缺失时按样式配置回退并记录。

```sh
python3 plot.py --out reproduced
```

`--out` 应指定不存在的输出目录，防止覆盖已交付图。原始输入位于 `input/`；6 个 CSV 和其余包内文件的 SHA-256 已逐项通过校验（共 12 项）。`figure-manifest.json` 保留列映射、处理规则、软件版本、点数和输出参数；`source_row` 对应原 CSV 行号（含表头）。

所有图注都在各图目录的 `caption.md`，未烘焙进图片。`qa/` 保留最终 PDF/SVG 渲染及检查记录；中间草稿不包含在分享 ZIP 中。
