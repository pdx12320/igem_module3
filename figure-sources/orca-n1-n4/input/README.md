## 3. N1 的关键数值（供你标注时核对）

组合批共 48 个构建体，其中 **36 个比值可定义**（12 个因 c.871 未检出、分母为零而不可定义，
**不得补 0**）。同批亲本 PUF12-9：比值 **1.192**、保留率 1.000（即 ROF 的分母）。

**帕累托前沿（比值与保留率同时最大化）共 6 个**：
`58M-130G`、`27D-30H-32F`、**`27T-30H-58M`**、`32F-132E`、`32F-58M`、`32F`

**三元组 `27T-30H-58M`：比值 2.156、保留率 0.773（ROF 1.809）**，两个基准下都是它最强：

- **保留率 ≥0.70 的构建体中，它的比值最高**（2.156；第二名 `25E-32F` 为 1.851）
- **它是唯一同时满足「比值 ≥2.0」与「保留率 ≥0.70」的构建体**

同时要如实呈现取舍：比值最高的几个构建体活性都很低
（`58M-130G` 3.714/0.292、`27D-30H-32F` 3.443/0.383、`27T-32F-132D` 2.864/0.377），
这正是图中要传达的另一半信息。

**可选的背景层**：把 `single_mutant_background.csv` 的 101 个单点画成浅灰小点置于组合点之下，
可以直观看到「组合突破了单点天花板」（单点中保留活性者的最高比值只有 1.71）。若版面拥挤可整层省略，
省略后 N1 仍完整。

## 4. ⚠ N2 的口径警告（这一条务必读）

`triple_record_across_batches.csv` 里有一列 **`cross_batch_value_comparable`**。

**第三批（2026-09-29）的建库背景与前两批不同**，其表现是整个批次的选择性被压缩
（该批最高的构建体比值也只有 1.33）。因此：

- 第三批的比值 **1.278** 与组合批的 **2.156**、补充批的 **2.083**
  **不可横向比较**——把它们并排画成柱状图会让人误以为特异性掉了近一半，而那是背景差异，不是构建体退化。
- **能跨批传递的是批内名次**（`rank_by_ROF_within_batch`、`rank_by_retention_within_batch`）。

**建议的画法**：若要画三批，请画 ROF 或批内名次，并在图内明确标注第三批背景不同；
最稳妥的做法是**只画 N1（组合批内部），把三批记录作为附表**放进正文，不画成图。
